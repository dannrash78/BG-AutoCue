# BG AutoCue 🇧🇬

Статичен GitHub Pages инструмент за запис на видео + autocue с гласово следене на **български (bg-BG)**.

## Какво прави

- Записва видео от камерата и звук от микрофона.
- Показва сценарий върху видеото като teleprompter.
- Има voice-follow чрез Web Speech API (`bg-BG`).
- Има ръчно превъртане и автоматична скорост като резервен режим.
- Настройва размер на шрифта и вертикална позиция.
- Записът се обработва локално в браузъра и се запазва като WebM.
- Няма backend, база данни или качване на видеото.

## Важно за българското гласово следене

Гласовото разпознаване зависи от браузъра и операционната система. В Chrome на Android поддръжката може да е налична, но не е гарантирана на всеки телефон/браузър. Инструментът изрично задава `bg-BG`.

Ако браузърът не поддържа `SpeechRecognition`, бутонът за voice-follow се изключва и можеш да използваш ръчно/скоростно превъртане.

## Публикуване в GitHub Pages

1. Създай нов GitHub repository, например `bg-autocue`.
2. Качи `index.html`, `style.css`, `app.js` и `README.md` в root директорията.
3. GitHub → **Settings → Pages**.
4. При **Build and deployment** избери **Deploy from a branch**.
5. Избери `main` и `/ (root)`.
6. Save.
7. Отвори генерирания HTTPS адрес на телефона.

### Защо HTTPS е важно

Камерата и микрофонът изискват secure context. GitHub Pages предоставя HTTPS.

## Препоръчителна употреба

На Android:
- Chrome
- предна камера
- телефонът стабилно поставен на стойка
- включи voice-follow
- започни видеозаписа
- говори нормално; прави естествени паузи

## Ограничение

Web Speech API не е еднакво поддържан във всички браузъри. За production вариант може да се добави отделен speech-to-text engine или локален модел, но това би увеличило размера и сложността на GitHub проекта.
