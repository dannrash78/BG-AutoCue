# BG AutoCue v3

Браузърен autocue за български текст с камера, запис и гласово следене.

## Какво е променено във v3

v3 комбинира работещите части от v1 и v2:

- Камерата се стартира напълно независимо от autocue и гласовия модул.
- Ако микрофонът не може да бъде даден, камерата пак се стартира.
- Autocue текстът използва голям отделен екран.
- Камерата е в малък отделен прозорец.
- Маркерът за лице е само върху камерата и не се смесва с текста.
- Големи бутони ▲/▼ за телефон.
- Ръчно движение, автоматична скорост и връщане в началото.
- Българско `bg-BG` SpeechRecognition.
- Има отделен тест на българското разпознаване.
- Гласовото следене се опитва да намира последните разпознати думи в текста и да премества autocue напред.
- Камерата и записът не зависят от SpeechRecognition.
- Записът се сваля локално като WebM (или MP4, ако браузърът го поддържа).
- Няма задължителна външна библиотека/CDN за основните функции.

## GitHub Pages

1. Създай repository, например `bg-autocue`.
2. Качи `index.html`, `style.css`, `app.js` и `README.md`.
3. GitHub → Settings → Pages.
4. Deploy from branch → `main` → `/root`.
5. Отвори HTTPS адреса на GitHub Pages.
6. Разреши Camera и Microphone.

## Важно за българското разпознаване

`SpeechRecognition` е браузърна услуга и поддръжката не е еднаква във всички браузъри. Затова v3 не разчита на нея за камерата.

Първо натисни **„Стартирай камера“**, после **„Тест на български“**. Ако в полето „Разпознат текст“ се появяват български думи, използвай **„Гласово следене“**.

Ако браузърът показва `network`, `not-allowed` или `service-not-allowed`, гласовата услуга не е предоставена от браузъра/мрежата. Ръчният autocue и камерата остават работещи.

## Камера

GitHub Pages е HTTPS и е подходящ за `getUserMedia`. Ако тестваш локално, използвай `localhost` или HTTPS, а не обикновен `file://`.

## Лицев маркер

Във v3 маркерът е визуален guide (овал + ъглови маркери), а не външна AI face-detection библиотека. Това е нарочно: така проблем с външен CDN не може да блокира камерата. Маркерът показва къде да позиционираш лицето.
