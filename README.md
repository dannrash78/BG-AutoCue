# BG AutoCue v2 🇧🇬

Autocue за Android/Chrome и GitHub Pages с българско voice-follow, запис на видео, големи бутони и отделен екран за текста.

## Важно
Гласовото разпознаване използва Web Speech API с `bg-BG`. Наличността и качеството зависят от браузъра/операционната система. Приложението показва реалния статус и грешката, вместо тихо да продължава.

## Функции
- bg-BG Speech Recognition
- по-устойчиво съпоставяне на речта със сценария
- отделен голям autocue екран
- малък прозорец за камерата
- големи ▲▼ бутони
- Face Detection рамка около лицето
- запис на видео + микрофон
- настройка на размер и прозрачност
- без собствен backend/база данни

## GitHub Pages
Качи `index.html`, `style.css`, `app.js`, `README.md` в repository. Settings → Pages → Deploy from branch → `main` → `/ (root)`.

Използвай HTTPS. Камерата/микрофонът изискват secure context.

## Поверителност
Сайтът няма собствен upload endpoint. Видеото се записва локално чрез MediaRecorder. Browser Speech API може да обработва аудио чрез услугата на браузъра/операционната система.
