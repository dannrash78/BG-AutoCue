# BG AutoCue

**Версия: 5.5**

Браузърен телепромптер с камера, запис на видео и гласово следене на български език.

Основни функции:
- Автокю и ръчно превъртане на текста
- Гласово следене на български
- Камера и видео запис
- Оцветяване на следващата дума
- Оптимизиран интерфейс за телефон и компютър

## Използване

Отвори `index.html` през HTTPS (например GitHub Pages) и разреши достъп до камерата и микрофона.
